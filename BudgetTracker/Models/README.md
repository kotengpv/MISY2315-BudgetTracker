# Models

This folder contains the classes that define the information used in our Monthly Budget Tracker.

## Files and Responsibilities

**Transaction.cs — Brandon**
- Stores information about each income or expense.
- Includes the amount, description, category, date, and transaction type.
- Provides the transaction information used throughout the application.

**MonthlyBudget.cs — Abyun**
- Stores monthly spending limits for different categories.
- Keeps track of the budget amounts set by the user.
- Provides budget information for the dashboard and calculations.

## Important
These classes store information. They do not create screens or handle button clicks.

Brandon and Abyun are responsible for developing and testing their assigned classes.
