# Forms

This folder contains the Windows Forms used in our Budget Tracker application.

- BudgetSettingsForm.cs — Set monthly budgets (Abyun)
- TransactionForm.cs — Add income and expenses (Brandon)
- DashboardForm.cs — View financial summaries (Kamden)
- MainForm.cs — Main menu and navigation (Kwame)

Each member is responsible for developing and testing their assigned form.
