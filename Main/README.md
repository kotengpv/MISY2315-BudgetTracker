# MISY2315-BudgetTracker

## Project Overview
This is a group project for MISY 2315 at Prairie View A&M University.

We are developing a C# Windows Forms application that allows users to track their daily income and expenses, set monthly budgets, and monitor their spending.

## Main Features
- Record income and expenses
- Set monthly spending limits
- View transaction history
- Calculate remaining balances
- Receive budget warnings

## Technology

- Windows Forms (.NET Framework)
- Visual Studio
